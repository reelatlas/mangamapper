## Traps learned (→ research-agent.md at capture)
- **A licensor's archived per-episode synopses can survive on the Wayback Machine** even when the live site is gone (TV Aichi's mewmew back-numbers: 23 of 52) — check `web.archive.org` for the broadcaster's episode pages before declaring "no licensor text".
- **ja-WP's ☆ / アニメオリジナル markers are a CONTROL when they leave adjacent rows unmarked** (shugo 91/92/97/98 unmarked beside 81-90 ☆) — read the unmarked rows as the positive claim.
- **"The episode titled X" ≠ "the episode where X happens"** (the Beat Jumper debut is ep 91; ep 92 is titled Beat Jumper) — a title-keyed annotation can be one row out; check the licensor synopsis for the beat.
- **A ruling keyed to a row number is stale after a renumber** (the A7 bound on shugo 93): every renumber apply must grep the rulings maps for keys inside the span, not only the DB tables.
- **AFL's date column is not a witness for a pre-2000 series** (FotNS 53/60/126: three non-Thursday dates no other source has, titles en-WP verbatim) — the day-of-week probe's hits were all real.
- **A game tie-in episode that PRECEDES the game is anime-original, not side_source** (shugo 85/86 set up the DS game) — the anime is the source of that material.
