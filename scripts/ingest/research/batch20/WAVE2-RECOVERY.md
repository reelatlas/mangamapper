## Traps learned (→ research-agent.md at capture)
- **AFL's "Manga Canon" on a licensed-novel block** (shippuden 484-500 ×17) is what manufactures a gap class entry; Narutopedia's EMPTY `Manga Chapter` field + AFG's "NOVEL" are the tell. A gap block on a finale should be identity-checked before it is researched as anchors.
- **ja-WP's 通算話 (cumulative-episode) column looks like a chapter column** on Shippuden's finale rows (700-720) — never join it.
- **A per-episode wiki field can DROP chapters silently** (kingdom.fandom: 274, 306, 310-311, 339-340 missing from a block whose neighbours are populated) and can carry another episode's line verbatim (Episode 78 = Episode 129's field). A chapter→episode reverse index (programming-cafe's anicomi list for kingdom; fandom chapter pages' `episode(s)` field for d-gray-man / hxh / yyh) is the antidote — always read BOTH directions.
- **AFG's chapter column can simply STOP mid-series** (eyeshield after ep 21) — an empty cell is not "no chapter"; and its typing column can be a verbatim copy of AFL's (d-gray-man 28/40), so AFL + AFG are ONE source for types.
- **A never-adapted range hides behind an afg-tier fence** (eyeshield 21 → 49 overshooting into 49-52, which no episode adapts in running order). A derivation-tier fence at a gap edge is a claim to re-derive, not a wall.
- **Title = chapter title is strong evidence but title ≠ content** (eyeshield ep 32 borrows ch 86's title while adapting ch 79; kingdom ep 90 至強 = ch 310 correctly). Confirm with a content beat.
- **The OVA date regime can be two-valued** (hxh G.I. Final: ja-WP's dates vs Nippon Animation's sell-through schedule, 2-3 weeks apart, both "official") — repair only where both regimes agree against the stored value; the regime choice is a series-level ruling.
- **Un-cross-cutting is a reorder shape** (bleach 152-159: parallel manga fights serialized one after another) — one END regression + one START back-jump, both `rearranged`, no position lost; the page-partitioned wiki fields (each shared chapter split exactly once across rows) are what make the anchors trustworthy.
- fandom `chapters=` fields stubbed on some rows (eyeshield's "Nth Down" pages; d-gray-man ep 38) — the CHARACTER / TECHNIQUE pages' debut fields form a reverse index (eyeshield: Ikkyu 49th Down ↔ Episode 37 exposed the 49-52 hole).
