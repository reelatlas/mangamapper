## Traps / instruments learned
- **A round-level anchor ('Round N complete') is a provenance, not a position** (RoK 17; the same provenance sits on 22 / 27 / 33 / 38) — a START taken from a round span is a phantom back-reach until refined on pages.
- **A graft promoted to a position** (beelzebub 46 / 47 END 115 with chapters {…, 115}): an AFG-tier row whose START is not its first chapter (A13) — the class the START clause exposes from the other side.
- **thetv.jp's episode page can print the PREVIOUS episode's synopsis** (beelzebub 50 → 49's text).
- **Dual-language subtitle archives (kitsunekko JA + EN) are a repeatable T28 sizing instrument** where AFG carries no page — bind the file to the row by an in-file cue (the next-episode title), never by index.
- **Sailor Moon's stored space is the 60-act renewal numbering**; the original 52-act count is a different space (renewal N = original N − 1 in the Black Moon region). Say which.
- **The fandom's page-partitioned `adapted=` field (RoK) is page-exhaustive** — parts union to the chapter page's own page count; that closure is the check.
