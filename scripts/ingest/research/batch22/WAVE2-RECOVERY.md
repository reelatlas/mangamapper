## Traps learned this wave
- **A sibling ADAPTATION's chapter titles can be our episode titles**: the 2022 Konoha Shinden manga (Jump+) titles ch 2 = ep 106, ch 11 = ep 110, ch 15 = ep 111 — a title-join would mistake it for a source. (boruto)
- **A wiki's structured field can be one user's resemblance promoted to a number** — pull the page HISTORY (edit summaries) when an SMW value stands alone against the page's own prose. (Narutopedia ep 106)
- **The stored side_story on a multi-segment episode can name the WRONG episode's extras** when two episodes share a shape (fma 13 / 37) — a segment-level check of 'which printed extra' is the instrument, not the note.
- **MangaDex's x.5 numbers on omake are scanlator sort keys** (fma 12.5 / 16.5 / 29.5; beelzebub 88.5) — a placement, never a chapter number (A44 / N35).
- **On DBS the fandom's 'entirely exclusive to the anime' and Kanzenshuu's own chapter note can contradict Kanzenshuu's synopsis of the same chapter** — read the synopsis, not the note. MangaPlus's API 403s; page images need another route.
- **Bandai Channel's per-episode synopsis text is in the served HTML** (the meta description is generic) — a licensor primary for 2010-12 series where the broadcaster's site has no per-episode text.
